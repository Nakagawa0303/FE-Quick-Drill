# FE Quick Drill

基本情報技術者試験 科目A・科目B向けの静的な演習アプリ。HTML / CSS / JavaScript ES Modulesのみで動きます。アカウント、バックエンド、外部API、ビルドは不要です。

## ローカルで使う

```sh
python -m http.server 8000
```

ブラウザで http://localhost:8000 を開いてください。ES Modulesを使用するため、HTMLファイルの直接起動（file://）では利用できません。Node.jsを導入済みなら `npm start` でも起動できます。

## 使い方

- 科目・分野・出題数を選んで演習開始。問題が足りない場合は利用可能な数に減らし、画面で案内します。
- 数字キー1〜9または選択肢をタップして解答。左右矢印・前後ボタン・問題番号で移動し、解答を変更できます。自動で次には進みません。
- 最終問題から採点。未解答は確認の上、不正解として扱います。不正解の解説を先に開き、正解の解説は折りたたみます。
- 不正解は復習対象へ自動追加。正解問題にも要復習マークを付けられます。復習対象は正解後も維持し、マークを押して解除します。
- 中断ボタン、タブ切り替え、ページを閉じる操作に対応。再アクセス時にホームから再開できます。経過時間は画面を表示して演習した時間で、バックグラウンド・中断中は計測しません。
- 学習記録からJSON書き出し・復元。復元は10MBまで。形式・バージョン・問題ID・選択肢・成績の整合性を検証し、確認後に全件を置き換えます。取り込む前に現在のデータを書き出すことを推奨します。

記録は同じオリジンの `localStorage`（キー `fe-quick-drill:v1`）に保存します。プライベートモード・ストレージ制限・ブラウザデータの消去により保存できない／消える場合があります。保存失敗は画面で通知します。別端末への自動同期や複数タブでの同時編集には対応していません。出題回数と正答率は採点済みの全履歴から集計します。

## ファイル構成

```text
index.html           画面の土台
css/style.css        レスポンシブデザイン
js/app.js            画面・操作・タイマー・JSON入出力
js/core.js           データ検証・出題・採点・集計（DOM非依存）
js/storage.js        localStorage入出力
data/questions.js    問題データ
tests/               出題・採点・復元・画面操作フローのテスト
```

## 問題を追加する

`data/questions.js` の `questions` 配列に次の形式で追加します。ビルドは不要です。IDは公開後に変更・再利用しないでください。既存の正答や選択肢の順序を変更すると、既存履歴とJSONの整合性が変わるため、新しいIDでの追加を推奨します。

```js
{
  id: 'A-T100',
  subject: 'A', // A または B
  field: 'テクノロジ',
  prompt: '問題文',
  choices: ['選択肢1', '選択肢2'], // 2〜20個。数字キーは1〜9、それ以外はクリック
  answer: 0, // 正答の0始まりインデックス
  explanation: { brief: '簡潔な説明', detail: '詳細な説明' },
  source: { type: 'ai', title: '出典の名称・年度・問題番号等' }, // ai / ipa / original
  verification: { status: 'pending' }, // レビュー後 verified に変更
  // verified の場合 method（検証内容）と date（検証日）が必須
  // code: '疑似言語\n  インデントを保持',
  // table: { headers: ['列名'], rows: [['値']] },
  // trace: { headers: ['変数'], rows: [[1]] },
}
```

分野名は `js/core.js` の `FIELDS` に定義した文字列に一致させます。未検証（`pending`）は通常演習・復習ともに出題しません。起動時に形式を検証し、不正な問題がある場合は問題ID付きのエラーを表示します。HTMLは埋め込まず、問題文・コード・表をそれぞれデータで定義してください。表示時には文字列をエスケープします。

### 初期問題の位置付け

科目A12問・科目B4問の独自AI生成サンプルです。正答計算・選択肢と解説の整合性をレビューし、数値・アルゴリズム問題の一部は独立計算テストでも確認しています。`verified` はこの開発時チェックを示し、IPA・専門家による認証を意味しません。試験の難易度・範囲を網羅せず、科目Bも短い動作確認用です。IPA公開問題はまだ収録していません。

追加するAI問題は、正答の一意性・前提条件・解説・トレースを人が確認してから `verified` にしてください。IPA問題を追加する際は公式の利用条件を確認し、年度・科目・問題番号・出典URLなどを出典情報に記録してください。

初期拡充目標は科目A60問・科目B12問、最終目標は科目A200問以上・科目B40問以上です。問題数はアプリ動作の前提条件にしていません。

## テスト

Node.js 20以上で依存パッケージ不要です。

```sh
node --test
```

主要ロジック7項目と、DOMアダプターを使った画面操作フロー1項目を用意しています。画面操作テストは実ブラウザの表示検証の代用ではありません。ブラウザでも科目切替・分野切替・演習・解答変更・中断再開・採点・復習・記録・JSON入出力を確認してください。スマートフォン幅ではコードと表が内容領域の横スクロールで読めることを確認してください。

## GitHub Pagesで公開

1. このフォルダの内容をGitHubリポジトリにpushします。
2. リポジトリの Settings → Pages → Build and deployment で Deploy from a branch を選択します。
3. 公開ブランチと `/ (root)` を指定し保存します。
4. 表示されたGitHub Pages URLを開きます。

すべて相対パスなのでプロジェクト配下のURLでも動作します。`.nojekyll` 同梱、ビルド設定や秘密情報は不要です。公開URLとlocalhostではブラウザ保存領域が別になるため、移行にはJSON書き出し・復元を使ってください。
