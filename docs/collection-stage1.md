1. **形式・重複**：全72問のID・正規化した内容・公式出典の重複、必須項目、選択肢、正答の範囲、公式解答記号、確認記録を検査。不正な問題・未検証問題の出題除外を回帰テストした。
2. **公式照合・独自解説**：追加56問について、公式の問題文・選択肢・解答例と、簡潔／詳細解説の整合性をAIでレビュー。表と疑似言語は原本ページ画像でも照合した。公式解答を推測で補った問題はない。
3. **独立計算**：科目Aの数値問題7問とSQL2問、科目B8問、合計17問を独立計算・実行で確認。SQLは実際に出題する選択肢のSQL文をSQLiteで実行して比較した。
4. **科目Bのトレース**：追加8問の表示トレース全行を独立実装の結果と比較。ビット演算は全256パターン、2進数変換は長さ1〜10の全2046文字列等、合計5382入力例で正答選択肢の一意性を検査した。再帰問題では配列の範囲外参照も検出する。
5. **アプリの操作処理**：全56問を実際の `js/app.js` のイベント処理へ渡し、不正解→中断再開→採点→二段階解説→復習→正解の112セッションをテスト。公式出典リンクの表示、復習マーク解除、古い学習履歴の保持と保存データの復元も検査した。DOMアダプターを利用した自動テストであり、実ブラウザの描画確認とは区別する。

計算の検査記録：[ipa-stage1-verification.json](ipa-stage1-verification.json)。科目Bの独立実装は汎用の疑似言語インタープリターではなく、今回の原本の手続を忠実にPythonへ転記したもの。候補の式は制限付きASTで実際に評価する。検査記録のコード・トレースのハッシュが変わると再レビューを要求する。形式検査やスクリプトの再実行によって `pending` を自動で `verified` に変更することはない。

## 再検査

```sh
npm run questions:check
npm run questions:verify
npm test
```

`questions:verify` はPython標準ライブラリのみで実行でき、ネット接続不要。既存16項目に新規56問の操作フロー1項目を加えた17項目と、生成JS／JSONの一致検査を行う。開発環境ではNodeコマンドがPATHにないため、同じテスト関数をNode実行ツールから直接実行した。

原本の再取得・候補作成は次の補助スクリプトで再現できる（通常のアプリ利用・再検査には不要）。候補作成では全問を `pending` にする。既存の収録JSONは上書きしない。

```sh
python -m pip install --target tmp/python pymupdf
python scripts/acquire-ipa.py
python scripts/render-ipa-qa.py
python scripts/curate-stage1.py
python scripts/verify-stage1.py --candidate
```

原本・抽出テキスト・ページ画像・候補JSON・PDF処理用依存は `tmp/` に置き、Git対象から除外した。
